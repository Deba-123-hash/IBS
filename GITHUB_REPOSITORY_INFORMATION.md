## 2. Architecture & Tech Stack
- **Frontend**:
  - React 18 Single Page Application (SPA)
  - Vite 5 build tool with code splitting and vendor isolation
  - Tailwind CSS with custom emerald brand and slate neutral system
  - Lucide React icon library
  - Three.js WebGL 3D architectural twin
  - Strict WCAG 2.2 Level AA accessibility compliance
  - Universal zero-latency non-animated standard
  - Pure light theme design system

- **Backend**:
  - Node.js & Express RESTful API Server
  - Prisma ORM 5 with Neon PostgreSQL connection pooling
  - Groq LPU integration with tool-calling triage capabilities
  - JWT authentication with HTTP-only cookies and Bearer tokens
  - Role-Based Access Control (RBAC) across 8 operational roles
  - Winston audit logger and centralized error handling middleware

---

## 3. Supported Operational Roles
1. **Super Admin**: System governance, tenant settings, and platform telemetry.
2. **Admin**: Student and staff master records, institutional analytics, approvals.
3. **Student**: Hostel allocation, mess menu, leave applications, gate passes, complaints, and timetable.
4. **Warden**: Room allocations, occupancy tracking, leave approvals, and student safety logs.
5. **Security**: Gate entry scan, cryptographic QR verification, and visitor pass log.
6. **Technician**: Maintenance work orders, SLA resolution, and utility breakdown logs.
7. **Accountant / Accounts**: Bursar fee collection, bank reconciliation, and expenditure journals.
8. **Faculty**: Academic schedules, attendance recording, and subject syllabus.
